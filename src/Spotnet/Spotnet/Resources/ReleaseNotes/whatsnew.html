Spotnet 3.0.8.0 NewCurrent version

  • .NET 10 included: Setup includes the Windows x64 .NET 10 runtime inside Spotnet's installation folder. No separate .NET installation is required; it does not appear as a separate entry in Installed Apps.
  • Remote password setup fixed: Enabling Remote for the first time asks for a password twice. Cancel keeps Remote disabled. Password settings remain accessible while Remote is off.
  • Password-only Remote login: The mobile login page no longer asks for a username. Existing passwords, paired devices and failed-login protection continue to work.
  • Updates before startup: The splash screen checks for updates before provider setup and database initialization. When an update is offered, startup waits for your choice. An unavailable update server times out after three seconds.
  • Startup crash fixed: The main window waits for server settings instead of firing its load handler too early.
  • New JSON spot cache: Replaces the obsolete binary cache for details and images. Old cached content is fetched again when needed. Corrupt cache entries no longer interrupt normal retrieval.
  • Existing profiles preserved: Upgrades keep databases and settings in place and do not create large automatic database backups.
  • Updated English and Dutch release notes inside Spotnet.

Spotnet 3.0.7.0 4 September 2026

🚀 Highlight: Spotnet Remote (Mobile Companion)

Control Spotnet directly from your smartphone or tablet! With Spotnet Remote, you have your entire Usenet catalogue in your pocket, anywhere in your home over Wi-Fi or on the go via port-forwarding.

  • [New] Spotnet Remote (Mobile Companion Web App):
    Wirelessly control Spotnet from any phone, tablet, or browser on your network:
    • Silent & Instant QR Pairing: Simply scan the QR code displayed in Spotnet using your mobile camera. Your phone is automatically authorized with a secure pairing token — no manual typing of usernames or passwords required on your mobile device.
    • Full Catalogue & Interaction: Real-time searching, filter synchronization with your PC, spot details and images, read comments, and post new comments with smileys.
    • Remote Downloads & Sync: Trigger NZB downloads on your PC or external downloader, and trigger Usenet synchronization remotely to fetch the newest spots.
    • Strong Security: Optional authentication with username and salted PBKDF2-SHA256 password hashing for safe remote access via port-forwarding.
    • Keep Computer Awake: Prevent your PC from falling asleep while Spotnet Remote is active via Windows execution state management.
  • [New] Live Titlebar Status Indicators for Remote:
    Convenient live status lights positioned in the titlebar next to the SPOTNET logo:
    • ● Green light (Active): Remote server is running and ready for connections.
    • ● Blue light (In Use): One or more mobile devices are actively connected.
    • ☀ Sun/Eye icon (Stay Awake): Sleep prevention is active, ensuring your PC stays on while using your phone.
    • ● Grey light (Off): Spotnet Remote is disabled. Click any indicator to quickly open settings or display the QR pairing code.
  • [New] Spotnet Notification Center & Alerts:
    Receive alerts for new content matching your interests:
    • Two Rule Types: Filter-based alerts or Keyword-based alerts (Pepper-style notifications for terms like F1, TV shows, or artists).
    • Flexible Intervals: Check periodically (every 15m, 30m, 1h, 8h, 24h, or custom minutes) or instantly upon each Usenet synchronization.
    • Smart Bundling: Bundles new spots into a single clean digest instead of spamming separate notifications.
    • Clickable Spots & Rule Editing: Open spots directly into Spotnet tabs, and easily edit existing rules anytime.
    • Desktop Integration: Native Windows Toast notifications and titlebar bell counter with unread badge.
  • [Fixed] Theme & Title Bar Alignment: Dialog windows (Settings, Notification Center, Remote Pairing, etc.) now inherit theme-consistent navy blue headers in light themes and deep slate in dark themes.
  • [Fixed] Release Notes Typography & Dark Mode: Squeezed, overlapping text permanently resolved with clean Segoe UI typography, generous line-height, modern card styling, and Dark Mode support.

What’s New


3.0.6.8
  • [Fixed] The What’s new in this version link in the update prompt now opens the Release Notes tab inside Spotnet, just like Help > Release Notes, instead of opening an external browser.

3.0.6.7
  • [New] Archive passwords are found on their own. Spotnet reads the password from the NZB’s own metadata, and failing that from the spot description, and hands it straight to UnRAR or 7-Zip. You are asked for a password only when none can be found or the one found turns out to be wrong.
  • [New] A first synchronisation no longer has to reach back fifteen years. Choose how far back to fetch — the last 30 days, 90 days, a year, or everything — and a new installation is ready in minutes rather than hours.
  • [New] Windows desktop notifications when a download has finished and unpacked, and when a database repair or rebuild is done. They appear only while Spotnet is not the window in front. Settings > Common has a switch and a button that shows one on the spot.
  • [Fixed] Links in a spot description opened an empty tab or did nothing at all. Web links now open in your own browser, or in a Spotnet tab if you prefer. Spotnet’s own links stay inside the application either way.
  • [Fixed] Dialogs and pop-ups kept fixed grey tones and could leave grey text on a grey background. Every window now follows the chosen theme, in Modern Dark, Modern Light and Classic alike.
  • [Fixed] Spotnet failed to verify par2 files on Windows installations running in FIPS mode. It now uses hashing Windows accepts there; par2 verification itself is unchanged.

3.0.6.6
  • [Fixed] Downloads could finish with a warning and unpack with a checksum error. The decoder kept the doubled leading dot the news server adds to a line, which inserted a stray byte into the file. Files already downloaded cannot be repaired — delete and download them again.

3.0.6.0
  • [New] Spotnet now runs on .NET 8. Setup installs the runtime if it is missing.
  • [New] Spot pages and their comments render in Edge WebView2; the old Windows browser control is gone.
  • [New] Search uses SQLite FTS5. The index is rebuilt once on first start.
  • [New] The list, list-with-details and thumbnail views moved to Edit > View.
  • [Fixed] Stored passwords and the signing key were truncated when longer than sixteen characters.
  • [Fixed] Setup now removes the previous version’s files, which could otherwise crash the application.
  • [Removed] The VPN Nederland integration is gone: the status-bar icon, the pop-up promoting it, and the button that downloaded and ran the provider’s installer. Settings simply advises using a VPN, naming none.

3.0.0.0
  • [Fixed] Fixed several minor bugs.
