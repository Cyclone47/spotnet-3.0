# Spotnet 3.0.14.0

## Nederlands

- **Automatisch herstel van RSA-sleutelcontainers:** Voorkomt opstartfouten (`CryptographicException`) door beschadigde Windows-sleutelcontainers automatisch te detecteren, veilig op te schonen en direct een schone werkende sleutel aan te maken.
- **Weergaveknoppen op de voorgrond:** Snelle knoppen voor weergavemodi (Lijst, Details, Afbeeldingen) zijn weer direct bereikbaar in de bovenbalk naast het menu, voorzien van scherpe pictogrammen en actieve markering. In- of uitschakelbaar via *Beeld* ➔ *Zichtbare controles* of *Instellingen* ➔ *Spots*.
- **Verbeterde venster- en menu-indeling:** De linkerzijbalk en menubalk zijn geoptimaliseerd, waardoor het Help-menu altijd zichtbaar blijft en de gekleurde genre-indicatoren in het filteroverzicht ruim en overzichtelijk worden weergegeven.
- **Ingebouwde spot-vertaling:** Mogelijkheid om spotbeschrijvingen direct in het spotoverzicht te vertalen naar de gewenste taal via een ingebouwde vertaaldienst.
- **Spotnet Remote reacties:** In de Spotnet Remote webinterface kunnen nu ook reacties op spots direct worden bekeken, inclusief verbeterde paginering en navigatieknoppen.

## English

- **Automatic RSA key container recovery:** Prevents startup crashes (`CryptographicException`) by detecting corrupted Windows key containers, safely cleaning them up, and automatically generating a fresh working key.
- **View mode buttons restored:** Quick view mode buttons (List, Details, Images) are back in the top toolbar next to the main menu with crisp vector icons and active highlight. Can be toggled via *View* ➔ *Visible controls* or *Settings* ➔ *Spots*.
- **Optimized toolbar and panel layout:** Left sidebar width and menu bar spacing have been adjusted so the Help menu is never clipped and colored genre indicators remain clearly visible in the filter tree.
- **Spot translation service:** Translate spot descriptions directly within the spot overview to your preferred language using the built-in translation service.
- **Spotnet Remote comments:** Spotnet Remote web interface now supports viewing comments on spots, complete with improved pagination and navigation controls.
