# Spotnet 3.0.16.0

## Nederlands

- **Het overzicht vult zich weer meteen:** De spotlijst wordt bij het opstarten als eerste geladen, zodat een traag tabblad met releasenotes, een promotie-ophaalactie of een migratie niet langer een leeg overzicht of een eindeloos draaiend rondje achterlaat. U hoeft geen filter meer aan te klikken om de spots te zien.
- **Geen vastgelopen venster meer bij de eerste start na een update:** Het tabblad Releasenotes houdt het opstarten niet meer op en haalt de changelog op de achtergrond op in plaats van op de interfacethread.
- **Laadindicator kan niet meer blijven hangen:** Door een timingprobleem kon het draaiende rondje aan blijven staan nadat het laden al klaar was. Beide spotweergaven verbergen de indicator nu tenzij er werkelijk geladen wordt.

## English

- **The overview fills straight away again:** The spot list is loaded before anything else at startup, so a slow release notes tab, promotion fetch or migration can no longer leave you looking at an empty overview or a spinner that never stops. Picking a filter is no longer needed to make the spots appear.
- **No more frozen window on the first start after an update:** The release notes tab no longer holds up startup, and its changelog is fetched in the background instead of on the interface thread.
- **Loading indicator cannot get stuck:** A timing problem could leave the spinner switched on after a load had already finished. Both spot views now hide the indicator unless a load is genuinely running.
