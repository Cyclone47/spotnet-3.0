# Spotnet 3.0.15.0

## Nederlands

- **Laadindicator bij opstarten opgelost:** De spotlijst blijft na het opstarten niet langer hangen achter een draaiende laadcirkel. Het overzicht laadt direct uit cache en de laadindicator verdwijnt automatisch zodra de spots gereed zijn.
- **Automatisch releasenotes tonen:** Na het installeren van een update wordt het tabblad Releasenotes automatisch geopend bij de eerste start, zodat u direct ziet wat er nieuw is.

## English

- **Startup loading fixed:** The spot list no longer stays stuck behind a loading spinner after launch. The overlay now only appears when data is genuinely still loading, and clears automatically when the initial load completes.
- **Release notes on update:** The Release Notes tab opens automatically the first time Spotnet starts after an update, so you always see what changed.
