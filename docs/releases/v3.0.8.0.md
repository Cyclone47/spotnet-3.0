# Spotnet 3.0.8.0

## English

- **.NET 10 included:** Setup includes the Windows x64 .NET 10 runtime inside Spotnet's installation folder. No separate .NET installation is required; it does not appear as a separate entry in Installed Apps.
- **Remote password setup fixed:** Enabling Remote for the first time asks for a password twice. Cancel keeps Remote disabled. Password settings remain accessible while Remote is off.
- **Password-only Remote login:** The mobile login page no longer asks for a username. Existing passwords, paired devices and failed-login protection continue to work.
- **Updates before startup:** The splash screen checks for updates before provider setup and database initialization. When an update is offered, startup waits for your choice. An unavailable update server times out after three seconds.
- **Startup crash fixed:** The main window waits for server settings instead of firing its load handler too early.
- **New JSON spot cache:** Replaces the obsolete binary cache for details and images. Old cached content is fetched again when needed. Corrupt cache entries no longer interrupt normal retrieval.
- **Existing profiles preserved:** Upgrades keep databases and settings in place and do not create large automatic database backups.
- Updated English and Dutch release notes inside Spotnet.

## Nederlands

- **.NET 10 inbegrepen:** De setup levert de Windows x64-runtime van .NET 10 mee in de Spotnet-installatiemap. Apart installeren is niet nodig; .NET 10 verschijnt daarom niet als afzonderlijke app bij Geïnstalleerde apps.
- **Wachtwoord instellen voor Remote hersteld:** Bij de eerste keer inschakelen vul je het wachtwoord twee keer in. Met Annuleren blijft Remote uit. Wachtwoordinstellingen blijven bereikbaar terwijl Remote uitstaat.
- **Remote-inloggen met alleen een wachtwoord:** De mobiele inlogpagina vraagt niet meer om een gebruikersnaam. Bestaande wachtwoorden, gekoppelde apparaten en bescherming tegen mislukte inlogpogingen blijven werken.
- **Updates vóór het opstarten:** Het splashscherm controleert op updates voordat providerinstellingen en databases worden geladen. Bij een beschikbare update wacht Spotnet op je keuze. Een onbereikbare updateserver vertraagt de start maximaal drie seconden.
- **Opstartcrash opgelost:** Het hoofdvenster wacht op de serverinstellingen voordat de laadcode wordt uitgevoerd.
- **Nieuwe JSON-cache voor spots:** Vervangt de verouderde binaire cache voor details en afbeeldingen. Oude cachegegevens worden zo nodig opnieuw opgehaald. Beschadigde cachebestanden onderbreken het ophalen niet meer.
- **Bestaande profielen behouden:** Upgrades laten databases en instellingen op hun plek en maken geen grote automatische databaseback-ups.
- Nederlandse en Engelse release notes in Spotnet bijgewerkt.

Application version / Applicatieversie: **3.0.8.0**.
