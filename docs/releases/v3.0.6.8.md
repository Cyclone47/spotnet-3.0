# Spotnet 3.0.6.8

## Fixed

- **Update notes now stay inside Spotnet.** Clicking *What's new in this version* in the
  update prompt opens or selects Spotnet's Release Notes tab, using the same page as
  Help > Release Notes, instead of opening an external browser. The modal update prompt
  closes first so the tab can be used immediately.

Application version: **3.0.6.8**. This remains the community reconstruction based on
Spotnet 2.0, not an official upstream release.
